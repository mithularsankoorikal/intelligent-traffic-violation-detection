Introduction About the Website

The Traffic Monitoring and Compliance System is an intelligent web-based platform designed to automatically detect traffic rule violations using computer vision and deep learning techniques. The system analyzes traffic videos to identify violations such as riding without a helmet and triple riding. By automating traffic monitoring, this system reduces manual effort, improves accuracy, and enhances road safety.

How It Works

The system accepts a traffic surveillance video as input. Each video is processed frame-by-frame using a YOLO (You Only Look Once) object detection model to identify vehicles, helmets, riders, and number plates. When a traffic rule violation is detected, the corresponding frame is captured and stored as evidence.

The detected violation images are displayed on the admin dashboard, where the administrator can verify the violation and issue a fine to the registered vehicle owner. The fine details along with the violation image are sent to the user via email. The user can log in to their dashboard, view pending fines, make the payment, and download a digital receipt after successful payment.

Technology Stack

Backend: Django (Python) for server-side logic, authentication, and database management.
Deep Learning Model: YOLO (Ultralytics) for real-time object detection and violation identification.
Computer Vision: OpenCV for video processing and frame extraction.
Frontend: HTML, CSS, JavaScript for user interface design and interaction.
Database: SQLite for storing user data, violation records, and fine details.
Email Service: SMTP integration for sending fine notifications and alerts to users.
